# 근거 정리: RSI 추첨 질량 재배분 (DRAFT v0.1)

**상태:** 결정 대기 (Thomas) — 이 문서는 결정하지 않는다. #717(절제 격자 첫 데이터 접촉)이
연 질문 하나 — *가장 많이 뽑히고 가장 많이 깎이는 조건(RSI)의 추첨 질량을 옮길 것인가* —
의 근거를 한곳에 모은 것이다. 수치의 재현은 전부
`scripts/condition_effectiveness_report.py`(집계)와 이 문서의 표(분해)이며, 원 데이터는
저장소의 격자 블록 76건(2026-08-12..08-16, 일 16개 균등)이다.

## 0. 한 줄

RSI는 템플릿 44개 중 18개에 박혀 있어 격자의 47%에 뽑혀 들어가고, 뽑힌 곳의 69%에서
깎이며, train에서 살아남은 경우조차 홀드아웃이 더 나쁘다 — 그러나 유일하게 양(+)으로
측정된 자리가 하필 **라이브로 arming된 그 계열(oi_unwind)**이고, 계열당 n=2라 어떤 개별
계열도 판정 해상도에 못 미친다.

## 1. 질문의 실체 — RSI 질량은 어디서 오나

- `factory.TEMPLATES` 44개 중 **18개(41%)** 가 RSI 조건을 갖는다(조건 슬롯으로는 108 중 18).
  faded 계열(funding/premium/taker_flow_fade), pullback/reversion 계열(trend_pullback,
  mean_reversion, htf_pullback, htf_reversal), 흡수·되돌림 계열(taker_absorption), 그리고
  **oi_unwind** — 전부 RSI를 확인(confirmation) 슬롯으로 쓴다.
- 로테이션은 균등하다. 08-12..08-16의 격자 76건은 38개 (family, tf) 셀을 **정확히 2회씩**
  (풀 5심볼 1 + BTCUSDT 단일 1) 방문했다. 즉 RSI의 36/76은 위상 편향이 아니라 **템플릿
  멤버십 폭** 그 자체다. 질량을 옮기는 실물 레버는 템플릿 정의(멤버십·파라미터 공간)뿐이고,
  배치 절반이 elite 중심 재추첨이므로 accepted에 RSI가 남는 한 질량은 자기 강화된다.

## 2. 측정 — 격자 76건이 말하는 것

**집계 (train 전용, 격자 내 대조):** RSI 등장 36격자, 평균 한계기여 **−0.077R**
(양수 9/36), 생존 11/36, 단독 생존 3. 조건 슬롯 기준 전체 추첨 어휘의 16%(36/228)를 점유.

**계열별 분해 (각 n=2 — 개별 셀은 판정 불가, 방향만):**

| RSI 한계기여 | 계열 |
|---|---|
| −0.58 … −0.17 | mean_reversion_short, trend_pullback, htf_pullback_long/short |
| −0.08 … −0.01 | premium_fade_short, funding_fade_long/short, taker_absorption_long/short, taker_flow_fade_long, mean_reversion, trend_pullback_short |
| ~0 … +0.01 | taker_flow_fade_short, premium_fade_long |
| **+0.04 / +0.15** | **oi_unwind_short / oi_unwind_long** |

음(−)이 16계열 중 12, 그리고 양(+)은 oi_unwind 둘뿐이다. **라이브로 arming된 유일한
전략(S005-GEN-833, oi_unwind_short 4h)의 진입 조건이 정확히
`[open_interest_change_pct, rsi]`다** — 전면 제거는 이 반례를 정면으로 밟는다.

**RSI의 운명별 홀드아웃 (기술 통계, 판정 아님):** RSI가 train에서 살아남은 후보(n=11)
p50 **−0.113R**, 깎인 후보(n=25) p50 0.000R, RSI가 아예 안 뽑힌 후보(n=40) p50 −0.001R.
train이 고른 RSI 생존자가 앞으로 안 간다 — 안티-RSI 방향의 가장 강한 신호이지만 n=11이다.

## 3. 이 데이터가 아직 말하지 못하는 것

- **독립성.** 76격자는 같은 1000일 창을 공유하고, 셀당 2스코프는 같은 데이터를 겹쳐
  리플레이한다(BTCUSDT는 풀 스코프 안에도 있다). 랩이 반복되면 파라미터-추첨 노이즈는
  줄지만 **시장 구간 독립성(~10구간)은 늘지 않는다** — 더 많은 격자는 더 많은 기간이
  아니다(풀드 민팅에서 이미 측정된 교훈).
- **계열당 n=2.** 위 분해는 방향 표시일 뿐 어떤 셀도 0.05R 해상도에 못 미친다.
- **재배분 유혹의 전과.** 2026-08-04에 같은 모양의 결정을 측정했다: 저표본 계열이 더
  좋아 *보였고*(+0.0212R vs −0.0064R), 그 차이는 t=+1.10에 분산이 더 넓은 노이즈
  시그니처였다. 민트-시점 변경의 같은날 판정은 #420에서 38% 틀렸다 — 세대 단위로 읽는다.
- **상한.** 널 컨트롤 기준 진입 신호의 총 기여는 ~0이고(실측 −0.1059R vs 랜덤 −0.1093R)
  홀드아웃 gross 엣지도 0이다. RSI 질량을 완벽히 재배분해도 움직이는 것은 그 0 근방의
  진입측 gross이며, 병목(청산+비용 기하)은 그대로다. 이 결정의 기대 효과는 작다 — 그래서
  급하지 않다.

## 4. 선택지별 근거 상태

| 선택지 | 근거 상태 |
|---|---|
| **0. 현상 유지** | 절제가 이미 추첨 단위 재배분을 수행 중(RSI 25/36 삭제, 등록은 최소 유효 부분집합). 유지 비용 = 어휘 슬롯 16% 점유 + train 생존자 11건의 하류 통과 시도(홀드아웃 문이 걸러냄). 측정은 매일 16격자씩 공짜로 쌓인다 |
| A. 전면 제거 (18템플릿에서 RSI 슬롯 삭제) | oi_unwind 반례 + LIVE 계보와 충돌. 현 데이터로 정당화 불가 |
| B. 부분 제거 (pullback/reversion 계열만) | 방향은 일관되게 음(−)이나 계열당 n=2. §5의 사전 등록 기준 충족 전에는 08-04 노이즈 시그니처와 구분 불가 |
| C. `rsi_min/rsi_max` 파라미터 공간 조정 | 측정 없음. elite 중심 추첨이 경계를 끈적하게 만들어 효과 판독도 세대 단위 |

## 5. 저절로 쌓이는 근거와 재독 시점 — B를 판정 가능하게 만드는 기준 (사전 등록)

1. **다음 랩:** 로테이션이 아직 안 방문한 RSI 계열(htf_reversal 등)을 포함해 전체 88셀
   (44템플릿 × 4h/1d)을 일 16격자로 도는 데 ~11일 — **2026-08-23경 1랩 완주**, 계열당
   n이 2→4+로. 개입 없이 온다.
2. **생존자 홀드아웃 추적:** RSI train-생존 후보의 홀드아웃 n=11 → **n≥30** 시점에 재독.
   p50이 여전히 비-RSI 대비 −0.05R 이하면 B의 1차 근거.
3. **독립 추정기 교차:** 널 컨트롤 게이트(`MIN_POST_MINT_DAYS=30`)의 첫 실측이
   **2026-08-28경** 열린다. 계열 단위 beats-fraction으로 RSI 계열을 교차 확인 — train
   격자와 다른 창, 다른 추정기다.
4. **판정식(제안):** 위 셋이 모두 같은 방향일 때만 B를 올린다 — (i) 2랩+ 누적에서 해당
   계열 RSI 한계기여 평균 < −0.05R **그리고** 양수 격자 0, (ii) 생존자 홀드아웃 조건 충족,
   (iii) 널 컨트롤이 해당 계열에서 랜덤 이하. 하나라도 어긋나면 현상 유지.

## 6. 권고

**선택지 0 + §5 재독.** 절제 격자가 이미 매 추첨마다 RSI를 개별 심사해 지우고 있으므로,
템플릿 수준 재배분이 지금 사는 것은 "심사를 건너뛰는 속도"뿐이고, 그 대가로 oi_unwind
반례와 08-04의 노이즈 시그니처 위험을 진다. 결정 재료는 ~1주(1랩) + ~2주(널 컨트롤)면
개입 없이 도착한다.

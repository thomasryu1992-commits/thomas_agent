  - **형식의 권위는 그대로 `crypto/account_store.py`다.** P2 구현은 `holdings/`가 읽는 칸의 집합을 시험으로 고정한다(`board.AGGREGATE_KEYS`와 같은 방식). 그래서 스냅샷 형식이 바뀌면 시험이 실패하고, 조용히 어긋나지 않는다.
    - 나이 판정은 `STALE_AFTER_SECONDS`(2시간)와 같은 창을 쓴다. 두 보드에 "너무 오래됨"의 정의가 둘이 되지 않게 하기 위해서다.
    - 원화 환산 환율의 출처는 P2 설계 때 정한다.
  - **지금 짓지 않는 이유:** KIS 보드가 `NOT_CONFIGURED`라 합칠 두 번째 계좌가 아직 없다. 순서는 KIS 키 → P1 운영 기록 → P2(합산 보드와 계좌 전체 한도)다(`MULTI_ASSET_EXPANSION_V0.1.md` §5).

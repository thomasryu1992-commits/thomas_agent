## 5. 모르는 것

1. **11-05 정산일이 설명되는가.** H6 준비는 `toss_cash_semantics` PASS에 달려 있고, 그것은 첫 매도의 정산 창이 설명돼야 한다 [모름]. 설명되지 않으면 시작점이 늦어지고, 이 문서의 날짜가 모두 밀린다.
2. **shadow가 실제 흐름을 맞게 처리하는가.** 합성 시나리오로는 시험했다 [확인: `tests/test_mvp_runtime_holdings_unit_shadow.py`]. 실제 입출금은 아직 한 건도 반영되지 않았다(2026-11-04 도어: 입금 0, 출금 0). 질문하는 날 Thomas가 터미널 보드의 `unit shadow` 줄을 직접 보고 확인하는 것이 HQ1의 근거가 된다.
3. **토스에서 은행으로의 출금이 토스 잔고에 언제 반영되는가.** 출금 요청 시점과 잔고 변화 시점이 다른 창에 걸리면 규칙이 닫지 못할 수 있다 [모름].
4. **G6-buy와의 관계.** G6-buy의 매수는 매매라 unit을 움직이지 않는다 [확인: S2]. G6-buy를 위해 넣는 돈은 입금으로 unit을 발행한다. 둘이 같은 창에 겹치면 규칙 v2가 입금으로 닫을 수 있는지에 달려 있다 [확인: v2는 같은 날 체결로 끝전을 설명한다]. 실제로 겹친 사례는 아직 없다 [모름].

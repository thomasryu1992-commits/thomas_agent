**갱신 (2026-08-17, 두 번째): §5-2/§5-3의 열린 파라미터가 실측으로 닫혔다 — 기본값
40bps/120분 → 25bps/240분.** 첫 프로브 4발 중 스톱 체결 1발·타임아웃 3발이었고, 타임아웃은
셀을 영구 소진한다(시도 = 승인 단위). 터치율 측정(15m 캔들 60일, 레짐 = 4h ATR(14) 백분위

25bps는 메이저 스프레드의 ~15배이자 이 상수가 섬기는 전략 스톱 중앙값(37.6bps)에 인접해
측정 전이가 성립하고, T 연장은 노출 시간만 늘릴 뿐 손실 상한(스톱)을 움직이지 않는다.
§3의 0.75% 상한은 승인가 그대로 두되 25bps에서 더 보수적으로 작동(실제 58.5bps). 기본
배치 정체성 해시가 이에 따라 이동했고(테스트가 새 정체성을 동결), 배치 2의 ACTIVE 플랜은
자기 해시(40/120)에 묶여 있어 영향 없다.

## 0. 한 줄

스톱 슬리피지 시리즈는 **라이브 스톱 청산에서만 자라는데**, 라이브 재개는 확증 게이트
(#694) 뒤에 있고 확증 시계는 34–69주다. 프로브는 이 순환을 **전략 없이** 끊는다: 최소
규모 포지션 + 지정 스톱 N회로, 비용 모델이 필요로 하는 표본만 사전 상한된 비용에 산다.

## 1. 왜 무장 재개가 답이 아닌가 (기각된 대안)

미확증 계보의 LIVE 무장은 `--allow-unconfirmed-holdout` 웨이버 — #648이 풀 전체를
무장해제했던 조건의 명시 면제 — 를 요구하고, 판정된 계보 전원이 CONTRADICTED인 모집단에서
음(−)의 기대값 거래로 비용 데이터를 사는 구조가 된다. 게이트 출고 당일의 웨이버 선례 비용이
데이터 가치를 초과한다.

## 2. 설계 (초안)

- **1회 프로브** = 시장가 진입(벤처 최소 노셔널) → 즉시 지정 스톱 설치(현행 팩토리 대표
  손절폭, 예: 진입가 대비 30–50bps) → 스톱 체결 시 종료. 스톱이 T bars 내 미체결이면
  시장가 청산 — 그 행은 슬리피지 표본이 아니다(표본은 스톱 체결만).
- **계측은 전부 기존 것 재사용**: #683이 이미 모든 스톱 청산에 `stop_price`를 스탬프하고
  `stop_slippage_bps`를 기록한다. 프로브는 새 측정 코드를 만들지 않고 그 경로로 행을
  만든다.
- **배치 구성** = N회(제안 12): 심볼 3종 × 변동성 레짐 상/하(atr_percentile 분기) ×
  2회, 시간대 분산. 슬리피지는 레짐 종속이므로 한 레짐에 몰린 표본은 상수를 다시
  왜곡한다.
- **오염 없음, 구조적으로**: 프로브 결과 행은 전략 계보를 갖지 않는다(candidate_id /
  generation 없음) — `forward_confirmation.lineage_keys`가 자연 배제하므로 forward 확증
  증거에 한 행도 섞이지 않고, lifecycle 사다리에도 귀속되지 않는다.

## 3. 비용 상한 (사전 계산 가능)

프로브당 최대 손실 ≈ 손절폭 + worst 슬리피지 + 왕복 수수료. 손절폭 40bps + 실측 worst
23.5bps + 수수료 ~10bps ≈ **노셔널의 ~0.75%**. 벤처 최소 노셔널(구현 시 심볼별 확인)이
~100 USDT면 프로브당 ≤0.75 USDT, **12회 배치 총 상한 ≤~9 USDT** — 등록 예산
(주문 ≤200, 일손실 ≤50) 내부이고, 배치 전체가 일손실 한도의 1/5 미만.

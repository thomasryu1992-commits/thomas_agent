# Personal branding is recorded as a hypothesis with read-off gates, not as a lane

- **Why now:** Thomas asked (2026-10-05) whether the blog's scope can extend to marketing and personal
  branding, and asked for the point at which to start to be judged and written down.
- **What this PR adds:** `docs/proposals/PERSONAL_BRANDING_EXPANSION_HYPOTHESIS_V0.1.md` (DRAFT) and
  `STATUS.md` regenerated. No code, no schema, no schedule.
- **The shape, and why:** the doc places branding at "Business Hypothesis" on the §15 path of
  `THOMAS_AUTONOMOUS_ORGANIZATION_ARCHITECTURE.md`. Each later stage opens on numbers the Sunday weekly
  review can read off, over consecutive weeks rather than one. The deciding measurement is
  neighbour-sourced views (이웃·서로이웃 조회), which were zero for five straight weeks while search
  carried about 87% of views. That is why stage 0 only adds measurement rows. Stage 1 waits for the
  Tistory verdict on 10-31, so a change of post style does not confound it.
- **What it deliberately does not do:** it does not re-propose the parked Kmong and Upwork tracks or
  the paused runtime blog lane. It names them as the things a passed gate gives evidence to revisit.
